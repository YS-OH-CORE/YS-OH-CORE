# Youngseok Oh

I turn observations from long-term human–AI interaction into source-separated, falsifiable evaluation designs.

My current work focuses on memory reconstruction, semantic fidelity, agent reliability, and discovery before naming. The aim is modest and practical: preserve the original signal, state what is interpretation, design a test that can fail, and publish results only after the test is run.

## Current work

- [The Second Paddle Notes](https://github.com/YS-OH-CORE/second-paddle-notes) — 18 evaluation designs derived from direct Korean source material, with hypotheses, failure conditions, and evidence boundaries kept separate.
- [Rule-Use Smoke Evaluation](https://github.com/YS-OH-CORE/second-paddle-notes/tree/main/experiments/rule-use-eval) — a reproducible public serialization and scoring check with deterministic fixtures; no language-model result is claimed.
- [The Second Paddle, Before Naming](https://youngseok-second-paddle.ohsycard.chatgpt.site/) — a short bilingual overview of the project and its five-case pilot design.

## Research standards

- Original wording, translation, editorial interpretation, hypothesis, design, and observed result are distinct layers.
- Model self-reports and memorable interactions are not treated as independent evidence.
- Negative controls, counterexamples, and failed runs are part of the result.
- Unrun designs remain labeled as unverified; no benchmark-performance claim is made before reproducible execution.
- Private source records and public research artifacts remain separate.

I welcome precise critiques, adversarial cases, and independent replications.
